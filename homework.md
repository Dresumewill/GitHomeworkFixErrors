## 2. What is JavaScript?

JavaScript is a high-level, interpreted programming language that runs in web browsers. It's main job is to run in a web browser to change or update HTML and CSS in real-time.

## 3. What three problems does Git & GitHub solve?

1. Version Control - If you accidentally delete important code, Git lets you restore the previous version instantly.

2. Collaboration and Teamwork - Two teammates can edit the same file at the same time, and Git will highlight any conflicts so they can be resolved cleanly.

3. Backup, Remote Access & Open Source Collaboration - If your computer crashes, you can clone your GitHub repository on a new machine and keep working without losing anything.

## 4. What happens when you `fork` a repository?

When you fork a repository on GitHub, you create your own personal copy of someone else’s project in your GitHub account.

## 5. What happens when you clone a repository?

When you clone a repository, you’re downloading a full copy of that Git or GitHub project from the cloud (remote) to your local computer.

## 6. What is a Pull Request?

A Pull Request (PR) is a feature in GitHub (and other Git platforms) that lets you propose changes from one branch or repository to another - typically from your fork or feature branch into the main project.
